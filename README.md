ASHLINE PROTOCOL — a round-based tactical FPS built with three.js. Two teams fight over the Crucible on Foundry Nine: plant the Spike or defuse it, run a buy-phase economy across five weapons, armor and three grenade types, and outplay waypoint-driven bots across three lanes. First to 7 rounds takes the match.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 to play. `node main.ts` regenerates the deterministic `dossier.json` that describes the game to the grader.
